# Syllabus

The full plan: **15 modules** + **8 workshops**. Work top to bottom. Each module pairs with a workshop and a set of exercises.

Estimated pace: ~3–5 hours per module. Don't rush — depth beats speed.

## Module completion rule

A module is **done** only when:

- [ ] You can explain the concept in your own words (write 3 lines in the module's `NOTES.md`).
- [ ] You completed its paired workshop.
- [ ] You solved its exercises with passing tests.
- [ ] You committed everything through a branch + PR (see [`docs/git-workflow.md`](docs/git-workflow.md)).

## Workshop quick list

1. [Git & repo setup](workshops/01-git-and-repo-setup/README.md) — set up your workflow
2. [TDD your first solution](workshops/02-tdd-your-first-solution/README.md) — test-first development
3. [Fixtures & parametrize](workshops/03-fixtures-and-parametrize/README.md) — real pytest skills
4. [Debugging with pdb](workshops/04-debugging-with-pdb/README.md) — stop using `print()`
5. [Profile & optimize](workshops/05-profile-and-optimize/README.md) — make it fast, prove it
6. [Code review](workshops/06-code-review/README.md) — review like a senior
7. [Evaluate an AI solution](workshops/07-evaluate-an-ai-solution/README.md) — find the subtle bug
8. [Capstone](workshops/08-capstone/README.md) — build your own problem set + CI
